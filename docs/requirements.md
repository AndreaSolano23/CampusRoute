# Requerimientos del Sistema

## 1. Lista general de requerimientos

El sistema de CampusRoute tiene los siguientes requerimientos:

### 1.1 Requerimientos funcionales

El sistema de CampusRoute debe tener la capacidad de:

- **RF-01:** Recomendar la mejor ruta según la preferencia del usuario
- **RF-02:** Registrar eventos que afecten las rutas o edificios 
- **RF-03:** Consultar edificios o instalaciones del campus. 
- **RF-04:** Autenticarse mediante eciApp. 


### 1.2 Requerimientos no funcionales

El sistema de CampusRoute debe tener:

- **RNF-01 (Seguridad):** Cifrado de las contraseñas de los usuarios almacenadas en la base de datos.
- **RNF-02 (usabilidad):** Interfaz que permita hacer las consultas.
